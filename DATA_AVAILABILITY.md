# Data availability and distribution policy

The MVA Genome Explorer repository provides research code and selected documentation for the two hackathon tracks. The patient whole-genome VCF, potentially identifiable genomic/clinical records, large external reference datasets, and caches are not distributed.

Use of patient data must comply with the original consent, authorisation, privacy obligations, and dataset terms. External databases (Ensembl/VEP, gnomAD, ClinVar, dbSNP, UniProt, AlphaFold) retain their own access and redistribution terms. Reproducibility should use properly authorised datasets or clearly labelled synthetic fixtures.

The public availability of source code does not automatically grant permission for redistribution. No open-source license has yet been chosen; an appropriate code license and attribution should be agreed before declaring the package redistributable.

A complete independently verified end-to-end installation is still pending. AI assistance and applicable data-handling settings should be disclosed in the full track-specific methods descriptions.

Track 2 candidate drugs are hypotheses only: no genotype-specific experimental rescue, cytotoxicity or clinical efficacy has been established.
